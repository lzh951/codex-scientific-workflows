# Tetris

A simple terminal-based Tetris clone built with Python and `curses`.

## Requirements

- Python 3.8+
- A terminal that supports `curses` (most Unix-like systems)

## Running

```bash
python tetris.py
```

### Controls

- **← / A**: Move piece left
- **→ / D**: Move piece right
- **↓ / S**: Soft drop
- **↑ / W**: Rotate
- **Space**: Hard drop
- **P**: Pause
- **Q**: Quit

Scores increase with line clears and soft drops. The game becomes faster as you clear more lines.
