# Android 手机 MCP 中继：极简外部版

适用于“Android 文件 MCP + ChatGPT”场景。用于发给同事/外部协作者，已去除敏感信息。

## 一句话

- `MCP` 链接会变。  
- 变了以后要重新从手机复制新地址，并同步到 ChatGPT 连接器。

## 30 秒恢复

1. 打开手机 MCP App。  
2. 确认本地服务在跑（能看到服务状态为 running）。  
3. 确认中继状态显示 connected（已连上）。  
4. 复制当前公开链接（完整 `https://.../d/.../mcp`）。  
5. 到 ChatGPT 的对应自定义应用，把地址改为新链接。  
6. 测试一句：  
   - `列出 /storage/emulated/0/Download`  

## 常见错误快速判断

- `Phone is not connected`：链接没更新或连接器未重连。  
- `502`：隧道链路断了，先重启/重新连接手机端中继。  
- `401`：授权失效，按授权页重新授权。  

## 外发时注意

- 不要公开发送 owner token。  
- 不公开真实设备 ID。  
- 不公开真实公网链接。  

## 最短建议（稳定性）

- 临时隧道每次启动可能换域名；生产用途请用固定 hostname 的正式隧道方式。
- 外部同事只按这份文档执行，不需要知道内部 token 和真实设备信息。
